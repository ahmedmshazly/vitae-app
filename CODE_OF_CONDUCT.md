# Code of conduct

Vitae is a place to build useful software with care for the people doing the
work. Treat contributors, users, and maintainers with respect.

## Expected behavior

- Be constructive and specific in technical discussion.
- Respect different experience levels, backgrounds, and working styles.
- Accept feedback about the work without turning it into a personal dispute.
- Protect private information and report security concerns through the private
  process.

## Unacceptable behavior

Harassment, threats, discriminatory language, unwanted sexual attention,
doxxing, deliberate disruption, and publishing private information without
permission are not acceptable.

## Enforcement

Maintainers may remove content, end a discussion, or restrict participation
when behavior violates this code. Report concerns privately through the
repository's security-advisory channel. Reports are handled as confidentially
as the circumstances allow.
