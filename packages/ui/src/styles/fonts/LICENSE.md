# Font licences

All three families ship under the SIL Open Font License 1.1 — free to embed, self-host and redistribute with the product.

- **Archivo Black** — Omnibus-Type. Display / wordmark. Weight 400 only.
- **Space Grotesk** — Florian Karsten. UI and body. 400 / 500 / 600 / 700.
- **Space Mono** — Colophon Foundry. Labels, reasons, chips. 400 / 700.

Files here are the latin subsets as served by Google Fonts. Full character sets: fonts.google.com.
