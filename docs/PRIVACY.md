# Privacy and sample data

Vitae stores highly personal information. A self-hosted deployment is operated
by its owner, who is responsible for access control, retention, backups, and
lawful handling of data.

The source repository contains fictional sample people, organizations,
projects, resumes, email addresses, domains, and screenshots. Do not add a
real export, contact list, resume, API credential, or production hostname to a
pull request.

Before sharing a bug report, export, screenshot, or log, remove names, email
addresses, account identifiers, source URLs, and metadata that can identify a
person. Use the demo space when reproducing an issue.

The project provides local export and restore tooling. Test a restore against a
non-production database before relying on it for recovery.

## Hosted Cloud status

The source project does not currently operate a public hosted data service or
receive a copy of self-hosted records. Vitae Cloud must not accept customer data
until a reviewed privacy notice, terms, data processing addendum, subprocessor
list, support route, retention/deletion policy, and operational controls are
published and enabled together. The [Cloud launch guide](CLOUD-LAUNCH.md)
records that gate; it is not a substitute for the published legal documents.
