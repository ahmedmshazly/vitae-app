# Governance

Vitae is maintained by the Vitae Maintainers group. Maintainers set the release
schedule, review contributions, handle security reports, and enforce the code
of conduct.

Technical decisions are made in issues and pull requests whenever practical.
Maintainability, data safety, backward compatibility, and documented behavior
carry more weight than novelty. A maintainer resolves disagreements after
considering evidence and user impact.

Major changes to storage, authentication, public APIs, or deployment policy
need an architecture decision record and an upgrade path. Contributors may
propose maintainers through a discussion after a sustained record of helpful,
responsible contributions.
