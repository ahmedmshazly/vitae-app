# Support

Use GitHub issues for reproducible defects and feature proposals. Use the
repository discussions area for setup questions, design discussion, and shared
operational experience.

Before opening an issue, check the documentation, current issues, and release
notes. Include the Vitae version, operating system, browser or runtime version,
and the smallest safe reproduction. Remove credentials and personal records
from every report.

Security reports follow [SECURITY.md](SECURITY.md), not the public issue tracker.
